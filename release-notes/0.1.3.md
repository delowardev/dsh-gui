# DeepSeek Harness (unofficial) 0.1.3

The release that makes installing and staying up to date boring.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/delowardev/dsh-gui/main/install.sh | bash
```

Verifies the download against the published SHA-256 before extracting, installs
to `/Applications` (or `~/Applications`), and clears the quarantine attribute.
This remains the only path that starts without a Gatekeeper prompt — see
"Known limitations" below for why that isn't a trick.

## What's new

**A one-command installer.** `install.sh` resolves the latest release, checks
`SHA256SUMS`, and refuses to install if it is missing or does not match. That
digest is what stands in for a code signature, so it is not optional.

**Self-update.** The app now checks for new versions and installs them in place,
verifying the payload against a minisign key baked into the binary. The harness
is stopped before the swap, and the app restarts into the new version.

**Runs signed with a stable identity.** Signed with an Apple Development
certificate, so macOS sees one consistent app instead of a new one every build.
Previously each update re-triggered the filesystem permission prompts.

**Downloads that survive a bad connection.** The ~66 MiB first-run download
resumes with HTTP Range instead of restarting, retries four times with backoff,
and reports what actually failed ("are you offline?" rather than a raw error).
There is a Retry button, and a retry resumes rather than starting over.

**A right-hand icon rail.** Agent and Terminal moved from a tab strip across the
top into an icon rail down the right edge, so the harness gets the full height of
the window.

**A first-run API key prompt.** The download leaves you with about eighty seconds
and one thing you cannot finish without, so the app asks for your DeepSeek API
key while it downloads. The key is checked against DeepSeek before it is stored,
so a typo surfaces immediately rather than as a failed first message. It is
written to the app's own harness home with mode `0600` and is never logged. You
can skip it and add it later.

**Clearer startup.** The loading screen no longer shows the Agent and Terminal
icons before they exist, and names each step — checking the runtime, downloading
the harness runtime, preparing the Web UI — instead of one unchanging message.

## Upgrading

**This one has to be installed manually.** 0.1.2 and earlier have no updater in
them, so they cannot see this release. From 0.1.3 onward, updates are automatic.

## Known limitations

- **Apple Silicon only.** Intel needs the `darwin-x64` runtime payload assembled
  and released first.
- **Not notarized**, so a browser download still gets a Gatekeeper prompt — that
  needs a paid Apple Developer Program membership for a Developer ID certificate.
  The `curl` installer is unaffected, because what Gatekeeper acts on is the
  quarantine attribute and `curl` does not apply one.
- The app keeps its own harness home under
  `~/Library/Application Support/io.github.delowardev.dshgui`. It does **not**
  read or write an existing `~/.dsh`.
